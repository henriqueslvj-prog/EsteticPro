# Edge Functions do EsteticPro

As Edge Functions deste projeto são usadas para integrações privadas, como o Google Drive das evoluções.

## WhatsApp

O EsteticPro não usa WhatsApp Cloud API/Meta para mensagens. O WhatsApp Business é configurado por profissional em Configurações → WhatsApp Business e o sistema abre links `wa.me` com a mensagem pronta para envio manual.
