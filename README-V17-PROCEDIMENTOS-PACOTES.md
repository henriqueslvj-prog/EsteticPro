# EsteticPro V17 — Procedimentos e Pacotes

Base: EsteticPro V16 — Ficha Profissional da Cliente.

## SQL
Execute `supabase/procedimentos_pacotes_v17.sql` no SQL Editor do Supabase antes de usar os módulos.

## Procedimentos
- cadastro de nome, categoria, duração, valor e descrição
- ativar/desativar
- edição e exclusão
- busca

## Pacotes
- cadastro de nome, valor, sessões, validade e descrição
- composição por procedimentos
- quantidade por procedimento
- edição e exclusão
- busca

## Observação
A V17 prepara a estrutura de pacotes e procedimentos para uma próxima etapa de venda/atribuição de pacotes a clientes e controle de sessões.
