# EsteticPro V24.8 — Tipografia da Anamnese

Ajuste visual solicitado na ficha de anamnese.

## Alterações
- Labels dos campos: 11px
- Texto dos inputs/selects/textarea: 12px
- Campos de entrada mais altos para melhorar legibilidade
- Textos auxiliares: 9px
- Notas de referência: 10px
- Títulos das seções: 23px desktop e 21px em telas menores
- Declaração e ciência: 12px
- Histórico de versões com tipografia ampliada
- Mantida a estrutura, dados, salvamento, histórico e PDF da V24.7

## Observação
A alteração é exclusivamente de legibilidade/estilo da ficha de anamnese. Nenhum campo ou estrutura de dados foi removido.
