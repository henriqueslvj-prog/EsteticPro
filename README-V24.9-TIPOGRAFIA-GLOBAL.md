# EsteticPro V24.9 — Tipografia Global

Atualização focada em legibilidade em todo o webapp.

## Alterações
- Aumento global das fontes pequenas presentes nos módulos.
- Labels de formulários ajustados para leitura confortável.
- Inputs, selects e textareas com tipografia maior.
- Navegação lateral e elementos de status/badges ajustados.
- Mantida a identidade visual, cores, estrutura e funcionalidades existentes.
- Ajustes aplicados também em mobile.

## Observação
A alteração é predominantemente de CSS. Não requer nova migration do Supabase.
