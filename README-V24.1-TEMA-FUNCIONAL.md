# EsteticPro V24.1 — Tema Claro/Escuro funcional

## Correção
A seleção em Configurações > Aparência agora altera imediatamente o tema visual de todo o aplicativo.

- Claro: aplicado imediatamente ao shell do EsteticPro.
- Escuro: retorna imediatamente ao tema original.
- A preferência continua sendo salva pelo botão **Salvar configurações**.
- O tema salvo é carregado ao entrar no aplicativo.
- O padrão é **Claro**.
