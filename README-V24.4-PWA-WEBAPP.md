# EsteticPro V24.4 — PWA + Navegação WebApp

Atualização sobre a V24.3.

## PWA
- Manifest com ícones PNG 192x192 e 512x512 derivados da logo oficial do EsteticPro.
- Apple Touch Icon para iPhone/iPad.
- `display: standalone` e `orientation: portrait-primary`.
- `theme_color` verde institucional.
- Service Worker para shell básico e abertura com comportamento de WebApp.

## Navegação
- Meta theme-color sincronizada com o tema claro/escuro.
- Navegação mobile com áreas de toque maiores.
- Safe area para aparelhos com notch e barra inferior.
- Botão “Mais” fica visualmente ativo quando um módulo secundário está aberto.
- Rolagem volta ao topo ao trocar de módulo.
- Sidebar mobile recebe melhor fechamento, sombra e área segura.
